
# 📊 Excel-Dashboard – Sales & Profit Analysis

An interactive and visually engaging **Excel dashboard** built to analyze and present key insights from a Sales and profit data. 
This project highlights strong Excel skills, including **data cleaning, PivotTables, dynamic charts, slicers, and dashboard design**.

---

### 📂 Project Structure
- **Sheet 1 – Dataset**  
  Cleaned and organized sales data including order details, dates, products, and revenue.  
- **Sheet 2 – Pivot Table**  
  Contains multiple PivotTables used as the backend for charts and KPIs.  
- **Sheet 3 – Dashboard**  
  The final user-facing dashboard with slicers, charts, and KPI summaries.  

---

### 📊 Features
- Daily and monthly sales tracking  
- Top-selling products and categories  
- Revenue and order trend visualization  
- Interactive filters for date and category  
- Clean and professional layout
